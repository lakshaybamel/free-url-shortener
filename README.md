# LiteURL – Free URL Shortener

LiteURL is a lightweight, full-stack URL shortener built using **Spring Boot** and **MySQL**.

This project was created as a learning-focused application to understand:
- Backend system design
- REST API development
- Database modeling
- Frontend integration
- Clean Git versioning and project structure

> ⚠️ This project is currently **paused** and will be extended in the future with more advanced features and cloud deployment.

---

## ✨ Features

- Shorten long URLs
- Optional custom alias for short links
- Redirect using short links
- Basic click analytics
- Clean and responsive UI
- No login, no subscription
- Single JAR full-stack application

---

## 🛠️ Tech Stack

- Java 17
- Spring Boot
- Spring Data JPA
- MySQL
- HTML, CSS, JavaScript
